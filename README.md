# SupportDesk Mobile 📱🎧

Мобильный тренажёр для инженеров технической поддержки. Написан на Python с использованием фреймворка **Flet**.

## 🎯 О проекте

Приложение помогает готовиться к собеседованиям и отрабатывать навыки диагностики сетевых проблем (L1/L2/L3). Внутри — база знаний, симулятор входящих заявок и продвинутый режим с ручным вводом команд.

### Основные возможности:
- **Справочник** — база знаний по сетям (OSI, TCP/IP, DNS, GPON и т.д.), глоссарий сокращений.
- **Тренажёр** — симулятор заявок с консолью и пошаговой диагностикой.
- **Продвинутый режим** — ты сам вводишь команды в консоль и интерпретируешь выводы.
- **Профиль** — сохраняет имя пользователя (SharedPreferences).
- **Автоскроллинг консоли** и подсветка ошибок.

## 🛠️ Технологии

- **Python 3.12+**
- **Flet** (Flutter-движок для Python)
- **JSON** для базы знаний и кейсов
- Работает на Android (сборка через `flet build apk`)
