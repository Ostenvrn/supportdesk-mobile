# SupportDesk Mobile 🎧📱

**Мобильный тренажёр и база знаний для инженеров технической поддержки (L1/L2/L3).**

Приложение разработано на Python с использованием фреймворка **Flet** (Flutter для Python). Работает на Android, а также может запускаться на Linux/Windows для разработки.

## 🎯 О проекте

**SupportDesk Mobile** — это портативный инструмент, который помогает готовиться к собеседованиям в телеком-компаниях (например, Ростелеком) и отрабатывать реальные сценарии поддержки абонентов.

### Основные возможности:

1. **📖 Справочник (База знаний)**
   - Более 10 категорий по сетевым технологиям (OSI, TCP/IP, DNS, GPON, VLAN и др.).
   - Подробные статьи с объяснениями и примерами.
   - **Шпаргалка по командам** (`ping`, `tracert`, `ipconfig`, `nslookup` и др.) с описанием, когда и где их применять.
   - Поиск по всем материалам.

2. **🎮 Тренажёр (Симулятор заявок)**
   - Два режима: **Обычный** (с подсказками и расшифровкой вывода) и **Продвинутый** (самостоятельный ввод команд в консоль).
   - Разделение по уровням сложности: **L1** (базовая диагностика), **L2** (сетевые проблемы), **L3** (инфраструктура, B2B, госучреждения).
   - Реалистичная эмуляция консоли с автоскроллингом.
   - Эмуляция **CRM (Биллинга)**: проверка баланса, статуса сессии и услуг абонента.

3. **📝 Тесты (Проверка знаний)**
   - Тесты для каждого уровня (L1, L2, L3).
   - 20 случайных вопросов в каждом тесте.
   - Проходной балл: 15 из 20.
   - **Разбор ошибок** после теста: объяснение, почему правильный ответ именно такой.

4. **🏆 Геймификация**
   - Более 30 достижений (ачивок) за различные действия: решение заявок, скорость, изучение тем, прохождение тестов и чтение статей.
   - Отображение прогресса и статистики.

5. **🌙 Тёмная тема**
   - Полноценная тёмная тема с адаптацией всех цветов (текст, фоны, кнопки) для комфортной работы в любое время суток.

## 🛠️ Технологии

- **Python 3.12+**
- **Flet** (UI-фреймворк на базе Flutter)
- **JSON** (хранение базы знаний, вопросов тестов и сценариев заявок)
- **SharedPreferences** (хранение прогресса, профиля и настроек)
- **GitHub Actions** (CI/CD для автоматической сборки APK)

## 🚀 Установка и запуск

### На Android (APK)

1. Скачай последнюю версию `.apk` из раздела [Releases](https://github.com/Ostenvrn/supportdesk-mobile/releases) или из вкладки **Actions** (артефакты).
2. Разреши установку из неизвестных источников на своём устройстве.
3. Установи приложение и запусти.

### Запуск из исходников (Linux/Windows)

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/Ostenvrn/supportdesk-mobile.git
   cd supportdesk-mobile
2. Создай виртуальное окружение и активируй его:
   python3 -m venv .venv
   source .venv/bin/activate  # Linux/macOS
   или .venv\Scripts\activate  # Windows
3. Установи зависимости:
   pip install -r requirements.txt
4. Запусти приложение:
   python app.py
